实验排班生成器 3.0.0：界面用原生 WinUI 3 重写，功能与 2.0.0（Electron 版）保持一致。

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `LabSchedule-3.0.0-win-x64-setup.msi` | **安装版**。默认装到当前用户（`%LocalAppData%\Programs\实验排班生成器`），不需要管理员权限，创建开始菜单和桌面快捷方式，可在"设置 → 应用"中卸载。 |
| `LabSchedule-3.0.0-win-x64-portable.zip` | **便携版**。解压后运行 `实验排班生成器-win-x64\LabSchedule.exe`，请保留整个文件夹。 |

两者都自带 .NET 运行时和 Windows App SDK，支持 Windows 10 1809 及以上 / Windows 11 x64。生成 PDF 需要 Microsoft Edge WebView2 运行时（Windows 11 自带）。

## 变化

- 原生 WinUI 3 界面：Mica 背景、系统标题栏按钮、跟随系统深浅色。
- 功能不变：插入/删除/复制、时间轴拖动和拖边缘改日期、联动后续安排、撤销/重做（Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z）、导入/保存/导出 JSON、生成 PDF、打开输出目录。
- 生成的 HTML 和保存的 JSON 与 2.0.0 逐字节相同；默认 JSON 仍在 `文档/实验排班输出/default_schedule.json`，升级后会自动加载原有排班。
- PDF 改由 WebView2（与 Electron 相同的 Chromium 内核）打印，版式与 2.0.0 一致。

注：程序未做代码签名，首次运行时 Windows SmartScreen 可能提示"未知发布者"，选择"仍要运行"即可。
