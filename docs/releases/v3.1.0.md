实验排班生成器 3.1.0：新增自动更新和设置页面，并修复实验列表最后一行无法完整显示的问题。

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `LabSchedule-3.1.0-win-x64-setup.msi` | **安装版**。默认装到当前用户（`%LocalAppData%\Programs\实验排班生成器`），不需要管理员权限，创建开始菜单和桌面快捷方式。已装 3.0.0 的直接运行即可升级。 |
| `LabSchedule-3.1.0-win-x64-portable.zip` | **便携版**。解压后运行 `实验排班生成器-win-x64\LabSchedule.exe`，请保留整个文件夹。 |

3.0.0 还没有自动更新功能，需要手动下载这一版；从 3.1.0 起，之后的版本都可以在程序里一键更新。

## 新功能

- **自动更新**：启动时检查 GitHub 上的新版本，在窗口顶部提示；点"立即更新"会下载并校验文件，然后自动安装、重启程序。安装版通过 MSI 升级，便携版直接替换程序文件夹里的文件。如有未保存的更改，会先询问是否保存。
- **设置页面**（命令栏右侧"设置"）：
  - 应用主题：跟随系统 / 浅色 / 深色，立即生效；
  - 默认开启"联动后续安排"；
  - 默认输出文件夹：可改到任意位置（默认 JSON、PDF/HTML 默认路径随之改变），可一键恢复默认；
  - 启动时自动检查更新开关、手动"检查更新"；
  - 关于：版本号、安装版/便携版、项目主页。

## 修复

- 窗口不够高时，下方实验列表的最后一行被面板边缘遮住、无法滚动出来。现在时间轴和列表按比例分配高度，列表随窗口一起伸缩。

注：程序未做代码签名，首次运行时 Windows SmartScreen 可能提示"未知发布者"，选择"仍要运行"即可。
