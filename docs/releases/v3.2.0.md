实验排班生成器 3.2.0：左右两栏和下方列表都可以拖动调整大小。

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `LabSchedule-3.2.0-win-x64-setup.msi` | **安装版**。默认装到当前用户，不需要管理员权限。已装 3.1.0 的会在程序顶部收到更新提示，点"立即更新"即可。 |
| `LabSchedule-3.2.0-win-x64-portable.zip` | **便携版**。解压后运行 `实验排班生成器-win-x64\LabSchedule.exe`；3.1.0 便携版同样可以在程序里一键更新。 |

## 新功能

- 左侧排班区和右侧"活动编辑"之间新增竖向分隔条，拖动可调整右侧编辑栏的宽度。
- 时间轴和下方实验列表之间新增横向分隔条，拖动可调整列表高度。
- 调整后的尺寸会记住，下次打开保持不变；双击分隔条恢复默认。
- 分隔条也可以用键盘调整：按 Tab 选中后用方向键移动。
- 窗口缩小时会自动收窄，左侧排班区至少保留 420 宽，时间轴和列表各保留最小高度，不会被挤出窗口。
