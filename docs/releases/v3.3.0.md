实验排班生成器 3.3.0：输出位置统一在设置页设置，主界面更紧凑。

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `LabSchedule-3.3.0-win-x64-setup.msi` | **安装版**。已装 3.1.0 及以上的会在程序顶部收到更新提示，点"立即更新"即可。 |
| `LabSchedule-3.3.0-win-x64-portable.zip` | **便携版**。解压后运行 `实验排班生成器-win-x64\LabSchedule.exe`；3.1.0 及以上的便携版也可以在程序里一键更新。 |

## 变化

- 去掉主界面右侧的"输出"区（PDF/HTML/默认 JSON 路径）。所有输出都放在设置页的"输出文件夹"里：
  保存 JSON 写入 `default_schedule.json`，生成 PDF 写入 `schedule_<年份>.pdf`、`.html` 和生成日志，设置页里会列出这些文件名。
- "插入实验 / 插入维护 / 删除"移到复选框那一行，主界面少了一整行；左栏较窄时这三个按钮会自动换到下一行。
- 左栏最小宽度调整为 600，拖动分隔条时标题等输入框不会再被挤没。
