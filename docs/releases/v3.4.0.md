实验排班生成器 3.4.0：每个实验可以添加和管理附件。

## 下载哪个

| 文件 | 说明 |
| --- | --- |
| `LabSchedule-3.4.0-win-x64-setup.msi` | **安装版**。已装 3.1.0 及以上的会在程序顶部收到更新提示，点"立即更新"即可。 |
| `LabSchedule-3.4.0-win-x64-portable.zip` | **便携版**。解压后运行 `实验排班生成器-win-x64\LabSchedule.exe`；3.1.0 及以上的便携版也可以在程序里一键更新。 |

## 变化

- "活动编辑"底部新增**附件**区，用来收集实验申请书、安全告知书、实验记录等文件：
  - 点"添加"选择一个或多个文件，或者直接把文件、文件夹拖到附件区；文件会**复制**到输出文件夹下的
    `附件\<开始日期 名称>\`（例如 `附件\2026-06-01 番茄种植观察\`），原文件不动。
  - 双击（或 Enter）打开；"⋯"或右键菜单里可以在文件夹中显示、重命名（F2，扩展名保留）、删除（Delete，移到回收站）。
  - "打开文件夹"在资源管理器里打开这个安排的附件文件夹，在里面直接放入、改名的文件，回到程序后会自动刷新。
  - 重名的文件会自动编号为"名称 (2)"，不会覆盖已有附件。
- 实验列表最后新增"附件"列，显示每个安排的附件数量，方便看出还缺哪些材料。
- JSON 里只为添加过附件的安排多写一个 `attachment_folder`（文件夹名），没有附件的文件格式不变。
- 删除安排不会删除它的附件文件夹，撤销即可恢复；"复制"出来的安排有自己独立的附件。
- 设置页的"输出文件夹"说明里写明了附件的位置。更改输出文件夹后，原来的附件需要连同"附件"文件夹一起移过去。
